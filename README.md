# Asset Tracker - Mobile App 

A professional Asset Management System built with Python + Kivy + SQLite.

Designed for small and medium businesses in Kenya to track company assets, employees, and assignments on Android.

## Features

- User Registration & Login
- Live Dashboard with Statistics
- Manage Assets (Add, Edit, Delete, Search, Filter by Category)
- Manage Employees (Add, Delete)
- Asset Assignments (Assign & Delete)
- Dark / Light Mode
- Backup Database
- Export to CSV
- Clean modern interface

## Requirements

- Python 3.8+
- Kivy 2.1.0 or higher
- Android device (for mobile use)

## Installation (Pydroid 3)

1. Install Kivy from Pydroid Pip
2. Place these two files in the same folder:
   - `main.py`
   - `asset_tracker.kv`
3. Run `main.py`

## Notes for Android

- On some devices with Python 3.13, Kivy may have graphics issues.
- For best results, package the app into an APK using Buildozer on a computer.

## Data Storage

All data is stored locally in `assets.db` on the device (private storage).
